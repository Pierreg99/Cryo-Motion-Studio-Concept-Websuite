# MOTION Asset Guide

## SVG Visual System

The `assets/` directory contains the standalone artwork used by the site.

| Asset | Role |
|---|---|
| `logo.svg` | MOTION gradient mark |
| `hero-visual.svg` | Hero monitor / abstract motion composition |
| `nova-visual.svg` | NOVA case-study artwork |
| `aura-visual.svg` | AURA case-study artwork |

All artwork is vector based, versionable as text, and works offline. No stock photos, remote image hosts, icon CDNs, or external font services are required.

## Art direction

The visual system uses translucent panels, soft blue-violet-pink gradients, clean geometry, organic ribbon forms and interface-like overlays. It is intentionally abstract so the portfolio remains lightweight while preserving a premium motion-design character.
