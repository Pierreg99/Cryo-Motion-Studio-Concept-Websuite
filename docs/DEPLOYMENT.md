# MOTION Deployment

## GitHub Pages

Use branch `main` and the repository root as the static publication source. `index.html` is the canonical entry point and `.nojekyll` remains in the root.

## Local

Clone the repository and open `index.html` directly, or serve the directory through any static HTTP server.

## Runtime

No build pipeline, package manager, framework runtime or external asset service is required. HTML, modular CSS, vanilla JavaScript and SVG assets are served statically.
