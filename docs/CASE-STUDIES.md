# MOTION — Case Studies

## NOVA

`projects/nova.html` is a dedicated deep-dive page for the NOVA / Digital Culture concept.

It covers the creative idea, design system, motion principles, implementation direction and selected system metrics. The page uses the existing local SVG assets and the shared `styles/case-studies.css` layer.

## AURA

`projects/aura.html` is a dedicated deep-dive page for the AURA / Wellness Tech concept.

It covers the sensory interface concept, interaction language, motion direction and system metrics. The page is linked from the portfolio overview and cross-links back to NOVA.

## Navigation

The portfolio cards on `index.html` now link directly to their respective case studies instead of terminating at the contact section.

## Offline behavior

Both pages use relative local asset and stylesheet references only. No external fonts, JavaScript libraries, image hosts or CDNs are required.

## Accessibility

Case-study navigation uses native links with descriptive labels. Visual-only artwork has meaningful alternative text where appropriate, while structural decoration remains in presentation roles.
